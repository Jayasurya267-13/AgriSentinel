# AgriSentinel

AgriSentinel is a secure and intelligent IoT-based smart farming system designed to improve agricultural efficiency and sustainability. The system uses an ESP32 microcontroller, soil moisture sensor, and 
temperature and humidity sensor to continuously monitor field conditions in real time. Based on the collected data, it automatically controls irrigation to reduce unnecessary water usage.
In addition to smart irrigation, AgriSentinel includes a Crop Stress Index (CSI) that analyzes environmental conditions to identify early signs of crop stress. To address the growing importance of cybersecurity in
IoT, the system also detects abnormal or tampered sensor readings and sends security alerts to the farmer through the Blynk cloud dashboard.
The project was first validated using Wokwi simulation and then implemented on real hardware. AgriSentinel combines IoT, edge intelligence, cloud monitoring, and cybersecurity to provide a low-cost, innovative, 
and farmer-friendly solution for modern agriculture.
